# Presentations archive

Archive of my talks, one directory per presentation.

Published on <https://www.alea.net/presentations-archive/> by [a GitHub workflow](./.github/workflows/pages.yml) on each push to `main`: every presentation listed in [presentations.json](./presentations.json) is built with Slidev (only when its content changed), and the index page is generated by [Eleventy](https://www.11ty.dev/).

- [Advent of Code: an introduction](./2026-11-advent-of-code-intro/) (November 2026)

## Building the site

### Publishing a presentation

Add an entry to [presentations.json](./presentations.json); `dir` must be a directory containing a Slidev deck (`package.json` + `slides.md`), and `date` is `YYYY-MM`:

```json
{
  "dir": "2026-11-advent-of-code-intro",
  "title": "Advent of Code: an introduction",
  "description": "30-minute talk encouraging developers to take part in Advent of Code.",
  "date": "2026-11"
}
```

Directories not listed there are neither built nor published. Push to `main` (or run the workflow manually from the *Actions* tab) to deploy.

### Building locally

The GitHub workflow runs exactly the same command:

```sh
npm install
npm run build   # whole site in _site/
npm run dev     # same, served with live reload on http://localhost:8080
```

[eleventy.config.js](./eleventy.config.js) builds each deck listed in `presentations.json` (running `npm ci` in its directory if needed), then the index page from [site/index.liquid](./site/index.liquid). Deck builds are cached in `.cache/`: a deck is only rebuilt when one of its files (local changes included) or the base path changes; delete `.cache/` to force a rebuild.

`PATH_PREFIX` sets the URL path the site is served from: `/` by default, `/presentations-archive/` in the workflow. Mind git-ignored `*.local.json` files: a local build bundles them, the published one does not (and changing them does not trigger a rebuild).

### GitHub configuration

In the repository *Settings → Pages*, the source must be **GitHub Actions**. The site is served under the custom domain of the `vhiribarren.github.io` user site.
