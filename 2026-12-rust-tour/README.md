# A Tour of Rust

45-minute presentation introducing the Rust programming language, built with [Slidev](https://sli.dev/).

- `npm install`
- `npm run dev`
- visit <http://localhost:3030>

Slides are in [slides.md](./slides.md); presenter notes include per-section timing.
